# nzyhacks

Bu site, siber güvenlik ve teknik konular üzerine notlarımı, çözümlerimi ve yazılarımı paylaştığım kişisel bir platform.

## Bu sitede neler var?

- **Hakkımda** — kim olduğum ve bu siteyi neden tuttuğum hakkında kısa bilgi
- **Bloglar** — güncel yazılar, düşünceler ve teknik notlar
- **Çözümler** — genel problem/challenge çözümlerim
- **Makine Çözümleri** — makine (machine) tabanlı görevlerin çözüm yazıları
- **Modül Çözümleri** — modül bazlı görevlerin çözüm yazıları

## Site hakkında

Site [Jekyll](https://jekyllrb.com/) ile oluşturuldu ve GitHub Pages üzerinden yayınlanıyor. İçerikler Markdown formatında yazılıyor, düzen ve tasarım `_layouts` ve `_sass` klasörlerinde tutuluyor.
