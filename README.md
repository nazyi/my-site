## Running Locally

Clone the repository:

```bash
git clone https://github.com/nazyi/nzyhacks.git
```

Go into the project folder:

```bash
cd nzyhacks
```

Install dependencies:

```bash
bundle install
```

Start the local server:

```bash
bundle exec jekyll serve
```

Open your browser and visit:

```
http://localhost:4000
```
